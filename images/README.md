## gallery/ subfolder

Your home kitchen food-making photos go in `public/images/gallery/` with names
`make1.jpg` … `make6.jpg` (list defined in `src/data/gallery.js` — add more
entries there if you have extra photos).

Until the real images are added, the UI shows graceful fallbacks.
